# Laundry Pickup & Delivery System

## 📌 Project Overview
This project is a Laundry Pickup & Delivery Application developed for the ONT401 Assignment.

The system allows customers to:
- Book laundry services
- Select laundry packages
- Add custom extras
- Make payments
- Receive order notifications

The project demonstrates the implementation of various software design patterns using C# and .NET Console Application.
